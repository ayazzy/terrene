# Wetland v0.1 real-data implementation plan

Inspected Earth Schema, existing overlay adapters, derived features, deterministic model, API submission/version pinning, worker leases, model UI, NATURE-INTELLIGENCE and VERIFICATION before implementation.

- **Blocking scored evidence:** slope; soil retention (currently only a normalized permeability index); watercourse distance; land cover and existing wetland extent/condition; development/infrastructure; incomplete irreplaceable-habitat evidence. Flood context is already available in a bounded Oxford corridor. Ecological proximity is optional; groundwater and hydroperiod are unassessed context.
- **Connect now:** authoritative EA 1 m composite DTM for actual elevation/slope calculations; authoritative OS Open Rivers for mapped watercourse proximity; practical open categorical land-cover raster, preserving its observation year and classification limits. Investigate defensible categorical soil drainage and major infrastructure without inventing values if access or meaning is insufficient.
- **Remain unknown unless real evidence supports them:** actual wetland condition, measured permeability/groundwater, reliable water supply, hydroperiod, small unmapped drains and complete intervention constraints. A bounded parcel DEM is not a complete upstream catchment; do not label local drainage proxies as catchment flow accumulation/TWI.
- **Reuse:** existing immutable object storage, Earth observations/assets, explicit unit and provenance validation, source selection, versioned model/feature signature, worker/API, EA flood and Natural England inventories. Preserve existing complete-component gates and all historical results. Expose useful partial components with categories and clear coverage rather than inventing an overall answer.
- **Verify:** actual site polygons and labelled comparison sample windows; retained real source responses and exact geometry; before/after input counts; binary EA WWNP reconnection benchmark overlap kept outside scoring. Test source mapping, real DEM calculations, unknown propagation, provenance and determinism; run retained suite, TypeScript and build.
